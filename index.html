An Android finance app built in Java (MVVM, Room DB) for tracking income, expenses, and monthly budgets. Features include category breakdowns, spending charts, CSV export, biometric lock, and a home screen widget, fully offline, no account or internet connection required.

Muscle Tracker

An Android workout tracker built from scratch in Java with a Room-backed MVVM architecture. Log sets by weight and reps, reps alone, or a live stopwatch for timed holds like planks, and export sessions straight to Strava via a reverse engineered .fit file encoder. Runs entirely offline.
